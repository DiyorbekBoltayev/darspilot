02 · sifat

Natija — «5/7» degan raqam

Bola qaysi qadamda adashganini bilmaydi: shartni tushunmadimi, ifodani noto'g'ri tuzdimi, hisobda xato qildimi yoki javobni noto'g'ri talqin qildimi.

03 · imkonsizlik

Bitta odam uddalay olmaydi

90 ta bolaga darajasiga mos masala tuzish, har birining xatosini nomlab izoh yozish, kim necha darsdan beri e'tibordan chetda qolganini yodda tutish.

Nega faqat «javob tekshirgich» yetarli emas

Feedback aniq bo'lishi uchun tizim faqat javobni emas, dars qanday o'tganini bilishi kerak: mavzu nima edi, kim bilan ishlandi, oldingi diagnostikada kim qayerda qoqildi, uyga nima berildi. Shuning uchun biz butun dars jarayonini tashkil qiladigan yordamchi qildik.

Kim uchun va asosiy qoida

Hozircha 5–6-sinf matematika o'qituvchilari; dvigatel fanga bog'lanmagan. O'quvchida qurilma talab qilinmaydi — qog'oz qoladi, o'qituvchining telefoni yagona qurilma. Javobni kod o'qiydi, AI faqat matn yozadi.

Struktura va tiplar

Qatlamlar aralashmaydi

  • main.py — faqat endpointlar: validatsiya va xatoni HTTP kodga aylantirish
  • service.py / conveyor.py — biznes mantiq; CV, AI va PDF alohida modul
  • TypeScript strict: API javobi tuzilishi types.ts da qat'iy yozilgan
  • npm run check — bitta buyruqda tsc + oxlint, 0 xato

Geometriyaning yagona manbasi

app/layout.py — kartochka o'lchamlari faqat shu yerda. PDF chizish, skaner va sinov generatori uchalasi shundan o'qiydi, shuning uchun ular hech qachon ajralib qolmaydi.
