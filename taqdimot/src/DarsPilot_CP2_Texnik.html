darspilot.com

demo@darspilot.uz / demo1234 — hozir ochib ko'rsangiz bo'ladi

Domen Cloudflare Registrar orqali olindi, DNS A-yozuvlari sozlandi.
Server — O'zbekistondagi VPS, Docker Compose: db + api + web (nginx).
HTTPS — Let's Encrypt, HTTP→HTTPS yo'naltirish, sertifikat cron bilan avtomatik yangilanadi.

Chiqqan muammo

Serverning protsessori eski

QEMU virtual CPU, x86-64-v1: sse4.2 va popcnt yo'q. Standart numpy «X86_V2 baseline» xatosi bilan, MinIO esa glibc xatosi bilan ishga tushmadi.

Yechim

Ikkita yig'ish varianti

Dockerfile ga ARG PY va ARG REQ qo'shildi; requirements-oldcpu.txt — Python 3.12 + numpy 1.26.4 + opencv-headless 4.10. Ombor esa MinIO o'rniga lokal papkaga o'tdi — app/storage.py da bitta interfeys.

Natija

Kod o'zgarmadi

Bir xil kod: lokalda MinIO + Python 3.13, serverda lokal ombor + Python 3.12, testlarda SQLite + lokal papka. Muhitga bog'liqlik konfiguratsiyada, mantiqda emas.

AI dizayni

Modelni qayerda ishlatamiz — va qayerda ataylab ishlatmaymiz

Kod hal qiladi (deterministik)

Sonlar, javob, ball

Masala sonlari va to'g'ri javob generatorda hisoblanadi (problems.py). Doirachalarni OpenCV o'qiydi (omr.py), javobni kod solishtiradi (grading.py). Baho — takrorlanadigan va tekshiriladigan: bir xil surat har doim bir xil natija beradi.

AI yozadi (matn)

Shart, feedback, xulosa

Masala matnini hayotiy qilib yozish, xato turini talqin qilish, o'quvchi/ota-ona/o'qituvchi uchun feedback, sinf xulosasi, dars ssenariysi. Vizual model — mashq daftari betlarini tekshiradi, transkripsiya modeli — o'qituvchining ovozini matnga aylantiradi.

Ishonchlilik

Har javob validatsiyadan o'tadi

JSON tuzilishi, sonlar, ismlar tekshiriladi. Mos kelmasa — shablon matn ishlatiladi, jarayon to'xtamaydi.

Kalitsiz rejim

Internet yo'q bo'lsa ham ishlaydi

llm.enabled() false bo'lsa, tizim shablon matnlar bilan to'liq ishlaydi. 47 ta test aynan shu rejimda o'tadi.

Shaffoflik

Har chaqiruv jurnalda

Maqsad, model, soniya, tokenlar va xato llm_calls jadvaliga yoziladi va /ai sahifasida ko'rinadi.

Kod tayyorligi

Testlar

47 ta test, tashqi servissiz

  • PostgreSQL o'rniga SQLite, ombor o'rniga lokal papka, AI o'chiq — pytest -q yetarli
  • Generator: har shablon × har daraja uchun javob va chalg'ituvchilar tekshiriladi

  • Bosma xavfsizlik: matn va markerlar qirqish chizig'idan uzoqligi test bilan qo'riqlanadi
Struktura

Qatlamlar aralashmaydi

  • main.py — faqat endpointlar: validatsiya va xatoni HTTP kodga aylantirish
  • service.py / conveyor.py — biznes mantiq
  • omr.py, llm.py, pdfgen.py — mustaqil modullar
  • TypeScript strict, npm run check bitta buyruqda tsc + oxlint

Geometriyaning yagona manbasi

app/layout.py — kartochka o'lchamlari faqat shu yerda. PDF chizish, skaner va sinov generatori uchalasi shundan o'qiydi, shuning uchun ular hech qachon bir-biridan ajralib qolmaydi. safety_report() chekkalarni qaytaradi, test uni tekshiradi.

Yangi ustun db.py:NEW_COLUMNS ga yoziladi va ishga tushganda ALTER TABLE bilan qo'shiladi. Shu tufayli serverdagi demo bazasi yangilanishlarda qayta yaratilmaydi.

Mezon 2 & 3 · maxfiylik
Maxfiylik va xavfsizlik

Bolalar ma'lumoti bilan ishlayapmiz — shunga mos qurilgan

AI ga nima ketadi

Ism emas, kod

Modelga 5B-17 kabi kod va agregat statistika yuboriladi. Ism, familiya va sinf ro'yxati serverdan chiqmaydi. Ovoz matnga aylantiriladi va saqlanmaydi.

Kirish

PBKDF2-SHA256, 200 000 iteratsiya

Parol hech qachon ochiq saqlanmaydi. Token HMAC bilan imzolanadi. Bazani tozalaydigan amallar kirishni talab qiladi — sayt ochiq internetda turibdi.

Ota-ona

Faqat o'z farzandi

Ota-ona portali maxsus token bilan ochiladi, boshqa o'quvchilar ko'rinmaydi. Direktor paneli ham ismsiz — sinf kesimida ishlaydi.

Nega bu texnik qaror ham

AI ga ism yubormaslik — bu faqat siyosat emas, arxitektura: kodlar service.py da almashtiriladi, promptlarda ism maydoni umuman yo'q. Shuning uchun keyinchalik model almashtirilsa ham maxfiylik buzilmaydi.
